Packaging adaptation
Each *.original.min.js file retains the upstream distribution bytes. The loaded
*.min.js file encloses those unchanged bytes in an application IIFE. A private
CommonJS module object selects the upstream export branch. A private globalThis
object catches js-sha256's compatibility export of sha224. Only the exports at
window.RescueManager.vendor.Papa / .sha256 are retained. No hashing or CSV parsing
algorithm is modified. Load js/namespace.js before these files. Workers and
remote/download parsing are not used by the application. Third-party source
URLs are license/provenance text and are never requested at application runtime.

Development tools
Node.js, Playwright, Python and browsers are development-only tools. They are
not runtime dependencies and must not enter the purchaser's distribution.
