    Comprobando control de escritura…

    Abre este mismo archivo en una segunda pestaña. El control se adquiere en IndexedDB; solo una pestaña puede conservarlo mientras el arrendamiento siga vigente.

    Dónde se guardan estos datos

    En el perfil de este navegador, en una base de prueba llamada rescue-manager-viability. Otro perfil, otro navegador o un cambio de carpeta puede mostrar un almacenamiento distinto. Limpiar los datos del navegador puede borrarlo. Las ventanas privadas pueden no conservarlo.

    Copiar esta carpeta no traslada la base del navegador. La aplicación comercial necesitará copias externas verificadas para mover o recuperar información.
